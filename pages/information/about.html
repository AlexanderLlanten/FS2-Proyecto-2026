SOBRE KYNEX

Nosotros

Tecnología, entrenamiento y suplementación integrados dentro de una misma experiencia digital.

QUIÉNES SOMOS

Una plataforma pensada para deportistas

KYNEX nace como una propuesta digital orientada a personas interesadas en entrenamiento, suplementación deportiva y desarrollo de hábitos relacionados con el rendimiento.

La plataforma combina una tienda online de suplementos con contenido informativo, herramientas de entrenamiento y funciones administrativas que permiten gestionar productos, usuarios y pedidos.

Ecosistema KYNEX

La propuesta busca conectar comercio, información y entrenamiento dentro de una experiencia sencilla, organizada y escalable.

NUESTRA PROPUESTA

Más que una tienda

KYNEX organiza distintas funcionalidades dentro de un único entorno digital.

Suplementación

Catálogo organizado de productos deportivos con información clara sobre características, precio y stock.

Entrenamiento

Espacio orientado a ejercicios, rutinas y material relacionado con la actividad física.

Información

Contenido destinado a complementar la experiencia con información sobre entrenamiento y suplementación.

PRINCIPIOS

Cómo se construye KYNEX

Experiencia simple

Una interfaz clara y responsiva que facilita la navegación entre productos, contenidos y servicios.

Desarrollo escalable

La estructura del proyecto está preparada para incorporar nuevas funcionalidades y una futura capa de backend.

Información organizada

Los productos y formularios se estructuran mediante reglas claras y validaciones orientadas a mejorar la experiencia del usuario.

Tecnología web

El proyecto utiliza HTML5, CSS, JavaScript y Bootstrap para construir una solución modular y mantenible.

DESARROLLO DEL PROYECTO

Equipo KYNEX

KYNEX es desarrollado como parte del proyecto académico de Desarrollo Fullstack II, integrando análisis, diseño y desarrollo Front End.

Equipo de desarrollo DSY1104

El equipo participa en la definición de requerimientos, construcción de interfaces, validación mediante JavaScript y control de versiones utilizando Git y GitHub.
